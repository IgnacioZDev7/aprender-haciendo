# MiTienda v1.0

Programa de consola para registrar las ventas de la tienda de Doña Rosa. Es el proyecto final del Libro 1, *Programar desde cero* (capítulo 10).

## Cómo ejecutarlo

```
python mitienda.py
```

Las ventas se guardan en `ventas.csv`, en la carpeta desde donde se ejecuta el programa.

## Pruebas

```
python test_mitienda.py
```

También funcionan con `pytest`, que se presenta en el Libro 2.
